# 客户端后端能力接入计划

## 产品目标

让普通用户可以在一个清晰、可恢复、可撤销的客户端流程中完成「发现作品 → 加入片库 → 参与社区 → 管理账号」的完整闭环。客户端只呈现用户权限内的能力；评论审核、封禁和运营统计继续留在独立管理端。

## 分阶段计划

### P0：用户闭环与账户安全

1. 发现页接入 `/api/v1/calendar`，提供按日期浏览当天开播作品的入口。
2. 社区页接入 `/api/v1/notifications` 与已读接口，支持回复、关注等事件的通知状态更新。
3. 评论卡片提供举报入口，接入 `/api/v1/comments/{id}/reports`，理由使用服务端允许的枚举。
4. 片库提供「移出收藏」，接入 `DELETE /api/v1/me/collections/{subjectId}`，并在成功后即时移除本地卡片。
5. 账户中心提供数据导出和注销账户，注销必须二次确认并在成功后清理本地会话。

### P1：社区关系

1. 动态卡片显示作者关注按钮，接入用户关注/取消关注。
2. 片单详情显示关注按钮，接入片单关注/取消关注。
3. 通知卡片提供作品、评论和片单的上下文跳转。

### P2：运营与管理端

1. 管理端接入评论审核、举报队列、操作审计和权限控制。
2. 同步后端 OpenAPI 与真实路由，避免管理端和客户端继续依赖过期契约。

## 验收标准

- 网络失败不会清空已有页面内容；所有写操作都有明确的成功/失败反馈。
- 删除、注销、举报等不可逆或高影响动作都具备确认或结果反馈。
- iOS 使用原生 SwiftUI Liquid Glass 作为根导航承载，业务页面继续复用 Compose Multiplatform；Android/Desktop/Web 使用同一套 Compose 页面。
- `animeCheck` 通过；Windows 本地完成通用编译检查，iOS 最终通过 GitHub Actions 进行 Xcode 构建和真机安装验证。
