# CMP 前端测试、性能预算与验收门禁

## 1. 测试分层

| 层级 | 重点 | 必须覆盖 |
|---|---|---|
| 单元测试 | Reducer、映射、校验、排序、状态转换 | 正常、边界、错误、取消 |
| Repository 契约测试 | Fake/Remote 行为一致 | 缓存、离线、旧数据、乐观写、冲突 |
| Compose 组件测试 | 语义、动作、布局 | 深浅色、200% 字体、无障碍 |
| 截图测试 | 视觉回归 | 关键组件和页面状态，不依赖网络 |
| 导航/UI 测试 | 完整用户路径 | 返回、登录回跳、进程恢复、Deep Link |
| 真机性能测试 | 启动、滚动、Glass、图片 | 低/中/高端机与代表 API |

## 2. Preview 与截图矩阵

公共组件必须覆盖 Light/Dark、360dp/600dp、100%/200% 字体、正常/空/错误、无图/长标题。页面截图至少覆盖：

- 发现：正常、一个 Section 失败、离线缓存、空数据。
- 搜索：默认、输入、结果、无结果、分页失败。
- 详情：完整、无评分、局部失败、未知章节数、同步冲突。
- 收藏：游客、五种 Tab 空态、在看列表、待同步和冲突。
- 短评：空、长正文、剧透、编辑草稿、提交失败。
- 设置：Glass 四档的可用/降级描述、Reduce Motion。

截图时使用固定 Fixture、固定时钟、固定 Locale、关闭系统动画和真实网络；动态 Liquid 只在真机视觉回归中检查。

## 3. 关键 UI 自动化路径

1. 冷启动进入发现 → 点击 Hero → 返回并保持位置。
2. 搜索长关键词 → 筛选 → 打开详情 → 系统返回恢复筛选。
3. 游客点击“在看” → 登录模拟 → 回到详情完成原操作。
4. 修改进度 → 显示 Pending → 模拟失败 → 重试成功。
5. 触发冲突 → 选择保留本机 → 标记解除且值不跳变。
6. 写 300 字短评 → 切后台/重建 → 草稿恢复 → 发布。
7. Deep Link 打开有效/无效条目 → 返回行为正确。
8. 切换 200% 字体和 Reduce Motion → 核心动作仍可达。

## 4. 性能预算

| 指标 | 目标 | 门禁 |
|---|---:|---:|
| Android 温启动到可交互 | ≤ 1.2s | P95 ≤ 1.5s |
| Android 冷启动到可交互 | ≤ 2.5s | P95 ≤ 3.0s |
| 常规页面切换 | ≤ 240ms 主动效 | 不等待网络结束 |
| 60Hz 列表慢帧率 | < 5% | P95 frame < 24ms |
| 详情首屏缓存渲染 | ≤ 500ms | 无全尺寸图片阻塞 |
| 搜索输入响应 | < 100ms | 建议请求可取消 |
| 内存中的首页海报解码 | 按容器采样 | 禁止批量原图 |

性能采样同时记录 Glass Tier。若 Liquid 使目标设备慢帧超过门禁，必须自动降级而不是放宽门禁。

## 5. 设备与系统矩阵

- API 26：最低支持、低内存、`None/Translucent` 降级。
- API 31：主流中端、Blur 能力与后台恢复。
- API 33：通知/媒体权限边界与系统主题。
- 当前稳定 API：预测返回、Edge-to-edge 和最新行为。
- 至少一台低端 4GB、中端 6–8GB、高端设备；模拟器不替代 Glass 真机测试。
- 手机竖屏/横屏、600dp 平板窗口、深浅色、中文/英文 Locale。

## 6. 无障碍门禁

- 自动扫描无缺失可访问名称、重复点击节点和小于 48dp 的关键目标。
- TalkBack 手工走通发现 → 详情 → 收藏 → 进度路径。
- 200% 字体下无裁切、重叠和不可滚动区域；键盘不遮挡提交按钮。
- 正文对比度 ≥ 4.5:1；大字/图标 ≥ 3:1；颜色不是唯一状态线索。
- Reduce Motion/Transparency 打开后，功能、焦点与阅读顺序不改变。

## 7. Feature Definition of Done

一个页面只有同时满足以下条件才算完成：契约与 UI State 已实现；所有规范状态有 Preview；Reducer/Mapper/关键交互有测试；截图基线评审通过；无障碍与 200% 字体通过；无真实网络也能演示；性能无新增回退；分析/日志不包含隐私；文档和路由表同步更新。

## 8. 建项后固化的命令

工程骨架建立后需把实际任务名写入 README 和 CI，目标命令如下（以最终 Gradle 模块名为准）：

```powershell
./gradlew.bat :shared:allTests :androidApp:testDemoDebugUnitTest
./gradlew.bat :androidApp:connectedDemoDebugAndroidTest
./gradlew.bat :androidApp:assembleDemoDebug
./gradlew.bat :androidApp:lintDemoDebug
```

合并请求至少运行静态检查、公共单元测试、Demo 构建和确定性截图；Release 分支另运行连接设备和性能门禁。
