# iOS 动漫卡片视觉与交互系统

> 编号：`CARD-1.0`  
> 日期：2026-09-15  
> 状态：Approved；适用于 R1 iOS，Android/CMP 复用同一比例和语义。

## 1. 统一 Token

| Token | 值 |
|---|---:|
| 页面边距 | 16pt |
| 栅格间距 | 12pt |
| 卡片内容间距 | 8pt |
| 普通卡片圆角 | 14pt |
| Hero 圆角 | 20pt |
| 海报比例 | 3:4 |
| Hero 比例 | 16:9，最小高度 188pt |
| 标题 | 最多两行 |
| 元数据 | 最多一行 |
| 可点击区域 | 最小 44×44pt |

## 2. 图片规则

普通海报永远放进固定 3:4 容器，`scaledToFill + clipped`，默认焦点为 x=0.5、y=0.35；禁止 `scaledToFit` 让图片以原始比例撑开卡片。Hero 使用单张横向背景加底部渐变，不再同时叠加一张完整竖版海报。

后端后续可提供 `focal_x/focal_y/image_kind`，没有焦点数据时使用默认焦点。加载、无图、失败状态使用统一占位，图片必须有无障碍标签。

## 3. 交互规则

- 一个卡片只有一个主导航目标；卡片内部不嵌套另一个 NavigationLink；
- 筛选按钮、状态按钮和删除按钮使用 `contentShape`，不把点击事件透传到卡片导航；
- 被推入的子页面不再创建嵌套 NavigationStack；
- 卡片尺寸由组件决定，页面只传入内容和密度；
- 轮播只裁切容器，不允许子视图改变父布局尺寸。

## 4. 验收

使用 20 张不同比例、人物位置和留白的真实海报检查：卡片宽高一致、标题不被裁切、人物脸不被默认焦点切掉、横幅不溢出、收藏筛选不误跳详情、VoiceOver 能读出作品名/评分/状态。
