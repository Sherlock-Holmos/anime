# CMP 页面详细规范

## 1. App Shell

App Shell 负责主题、窗口 Insets、类型安全导航、根导航、全局 Snackbar 和登录返回意图；不直接加载业务数据。启动顺序为本地设置 → 会话快照 → 首屏 Fixture/缓存，任何远端刷新都不能阻塞首帧。

## 2. 发现页

```text
┌ 流光标题 / 搜索入口 / 头像 ┐
│ [本季焦点 Hero（仅一个）]   │
│ 正在热播              全部  │
│ [海报][海报][海报] →        │
│ 最近更新              全部  │
│ [横向紧凑条目列表]           │
│ 为你发现              全部  │
│ [双列海报网格……]             │
└ 发现  搜索  收藏  我的 ┘
```

- 首屏输入：Hero、热播、最近更新三个独立区块；每块允许独立失败和重试。
- 下拉刷新保持旧内容，顶部显示轻量进度；刷新失败显示 Inline 状态，不清空列表。
- Hero 使用 `StaticHero/Liquid`，列表卡无实时玻璃。点击任意卡进入详情并恢复原滚动位置。
- 空数据时显示产品说明和“去搜索”；完全离线但有缓存时展示缓存与更新时间。
- 验收：冷启动 2.5 秒内可操作；区块错误互不连坐；重复条目在同区去重。

## 3. 搜索页与结果页

```text
┌ [返回?] [搜索作品、人物…… ×] ┐
│ 最近搜索  [清空]              │
│ 热门： [奇幻] [日常] [科幻]   │
│ 筛选：类型 / 年代 / 状态       │
│ ─── 提交后进入结果 ───        │
│ “葬送”  23 个结果      [排序]  │
│ [海报] 标题 / 年份 / 评分      │
│ [海报] 标题 / 年份 / 评分      │
└──────────────────────────────┘
```

- 输入 300ms debounce 仅用于建议；用户提交后生成结果路由，便于恢复与 Deep Link。
- 空查询不请求；搜索历史仅存在本地，可单条删除和全部清空。
- 筛选 Sheet 支持类型、年份、播出状态；“重置”与“应用”位置固定。
- 新查询取消旧任务；分页触底前 4–6 项预取，失败在列表尾重试。
- 无结果保留查询与筛选，提供“清除筛选”；离线无缓存明确提示不能搜索。
- 结果中的评分只显示 Bangumi 来源数据。

## 4. 条目详情页

```text
┌ 沉浸背景 + 返回 / 分享 ┐
│ [海报] 标题             │
│        原名 / 年份 / 类型│
│        [想看/在看按钮]   │
├ Bangumi 8.2  12,345人 ─┤
│ 评分分布（只读）         │
├ 简介 ──────────────────┤
│ 展开/收起的完整简介      │
├ 章节与进度 ─────────────┤
│ 已看 3 / 12  [-] [3] [+]│
├ 角色人物 / 关联条目 ────┤
├ 短评                  全部│
└────────────────────────┘
```

- Hero 背景为剧照/海报派生静态图层；主要文字落在稳定遮罩或表面上。
- 收藏按钮对游客可见，点击后通过 AuthGate 登录并返回继续操作。
- Bangumi 评分区始终带来源、票数和更新时间；无评分不占用巨大空白。
- 简介、章节、人物、关联、短评可分请求；失败只替换对应 Section。
- 进度编辑先本地生效，显示待同步；失败不回滚用户可见值，进入同步错误状态。
- 分享使用平台 SharePort；Fixture 构建生成可复制的测试链接。
- 验收：长标题、无海报、无评分、未知总章节、局部失败、旧缓存均有确定布局。

## 5. 收藏页

- 顶部状态 Tab：在看、想看、看过、搁置、抛弃；默认进入“在看”。
- 每项显示海报、标题、当前/总进度、最近操作和同步状态；在看项可直接增减进度。
- 支持标题排序、最近更新排序和本地筛选；首版不做复杂自定义列表。
- 游客展示说明、示例卡和登录按钮；不是空白错误页。
- 空状态按当前 Tab 描述，例如“还没有在看的作品”，提供“去发现”。
- 同步冲突项置于列表顶部但不改变用户筛选；点击进入比较/处理 Sheet。

## 6. 短评页与编辑页

- 短评页顶部显示条目简要信息、排序（最新/较早）和“写短评”。
- 加载更多在列表尾；自己的短评显示菜单，别人的短评不展示不可用操作。
- 剧透文本默认遮罩并提供语义化“显示剧透内容”按钮。
- 编辑页保持 0–300 字、剧透开关、草稿恢复和提交状态；系统返回时有未保存草稿则确认。
- 发布成功后返回列表并定位新短评；Fixture 模式标记本地数据，Remote 模式使用服务器时间。

## 7. 我的、设置与诊断

**我的**：登录用户显示头像、昵称、收藏概览、同步状态；游客显示登录价值说明。入口包括同步、设置、关于。

**设置**：主题（跟随系统/浅色/深色）、玻璃效果（自动/降低/关闭）、减少动态、数据与缓存、隐私、关于。系统无障碍偏好高于应用内视觉设置。

**Demo/诊断**：仅 `demoDebug`/`devDebug` 可见，显示数据模式、场景、延迟、当前 Glass Tier、缓存摘要和重置按钮。切换场景需立即可复现但不得在 Release 暴露内部信息。

## 8. 跨页面验收

- 所有页面覆盖 Loading、Content、Empty、Offline、Error、Stale 和 200% 字体。
- 页面恢复后保留根 Tab、详情 ID、搜索条件、列表位置和未提交草稿。
- 键盘弹出不遮挡主要按钮；横屏和折叠屏窗口变化不丢状态。
- 任意局部失败不能抹掉其他成功数据；重试只重试失败的请求。
- 所有评分文案均明确为 Bangumi 只读数据，界面中不存在打分控件。
