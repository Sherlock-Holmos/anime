# 玻璃、动效、无障碍与性能规范

## 1. Glass 能力分级

`GlassTier` 表达能力而不是设备品牌。页面声明期望等级，平台适配器按 API、功耗、无障碍偏好和运行性能选择实际等级。

| Tier | 表现 | 允许场景 | 降级 |
|---|---|---|---|
| `None` | 不透明语义表面 | 省电、低端机、减少透明度 | 无 |
| `Translucent` | 半透明色 + 高光边，无实时模糊 | 列表浮条、低成本容器 | `None` |
| `Blur` | 背景模糊 + 色调 + 边框 | TopBar、BottomBar、Sheet | `Translucent` |
| `Liquid` | Blur + 受限形变/折射/光泽 | 根 Tab Bar、Hero 聚焦或关键浮层 | `Blur` |

业务代码只能使用角色：`TopBar`、`BottomBar`、`FloatingPanel`、`Dialog`、`StaticHero`，不能直接操纵第三方 Backdrop 参数。

## 2. 角色 Token

以下值是项目视觉目标，具体映射由 Backdrop 适配层完成，不承诺与第三方 API 一一对应。

| Role | 首选 Tier | 模糊半径目标 | 容器不透明度 | 边框/高光 | 限制 |
|---|---|---:|---:|---|---|
| `TopBar` | Blur | 20dp | Light 72% / Dark 68% | 1dp, 28% | 默认透明，仅独立按钮组或滚动边缘使用玻璃 |
| `BottomBar` | Liquid | 24dp | 64% / 58% | 环形高光 + 悬浮柔影 | 手机端圆角悬浮、内容从下方经过；每屏仅一处 |
| `FloatingPanel` | Translucent/Blur | 16dp | 82% / 78% | 1dp | 不覆盖大段正文 |
| `Dialog` | Blur | 28dp | 88% / 84% | 1dp + scrim | 可读性优先，可直接不透明 |
| `StaticHero` | Liquid | 28dp | 58% / 54% | 柔和高光 | 每屏最多一处，不随列表复用 |

Tint 来自语义表面与海报主色的低饱和混合，海报色占比不得超过 12%。玻璃后的文字必须使用稳定语义前景色，禁止随背景像素逐帧变色。

## 3. 性能护栏

- `LazyColumn`/`LazyGrid` 的每一项禁止使用实时 Blur、Lens 或持续 Shader 动画。
- 一屏最多两个持续 Blur 区域、一个主要 Liquid 区域；根 Tab Bar 存在时，内容层不得再创建持续 Liquid，静态 Hero 自动降为 Blur。
- 滚动速度超过阈值时冻结玻璃采样或降级为 `Translucent`；滚动停止 120ms 后恢复。
- 低内存、系统省电、减少透明度、窗口后台或检测到连续慢帧时自动逐级降级。
- Android API 26–30 最高 `Translucent`；API 31–32 最高 `Blur`；API 33+ 在未触发其他降级条件时最高 `Liquid`。该映射由 `androidMain` 的 Backdrop 适配器和版本边界测试固定。
- 玻璃失败不能影响导航和点击；适配器发生异常时本次会话锁定 `None` 并记录诊断事件。
- 图片解码、渐变和 Glass 不在同一帧集中启动；首屏先显示稳定表面，再渐进增强。

## 4. 动效 Token

| Token | 时长 | 用途 |
|---|---:|---|
| `motionInstant` | 100ms | 按压、图标状态 |
| `motionFast` | 160ms | Chip、局部淡入淡出 |
| `motionNormal` | 240ms | 页面内容切换、展开 |
| `motionSlow` | 320ms | Sheet、共享视觉过渡 |

- 标准进入曲线：`cubic-bezier(0.2, 0.0, 0.0, 1.0)`；退出：`cubic-bezier(0.4, 0.0, 1.0, 1.0)`。
- 页面级动效只表达空间关系，前进轻微左移，返回反向；距离不超过 24dp。
- 同时动画的主元素不超过三个；Skeleton 的微光可被系统“减少动画”关闭。
- 收藏切换使用 100–160ms 图标/颜色反馈，不使用庆祝粒子；错误不得抖动整个屏幕。
- 列表项首次进入可淡入，但回滚、刷新和分页不可重复编排瀑布动画。
- 根 Tab Bar 的选中玻璃在拖动期间连续跟手并产生受限横向形变；松手后以阻尼弹簧吸附最近目的地。页面切换只在吸附目标确定后发生，拖动预览不能触发多次导航。

## 5. 触感与声音

- 轻触反馈：收藏状态切换、筛选确认；成功反馈：进度保存；警告反馈：破坏性确认。
- 滚动、普通导航、每次输入字符不触发震动。
- 尊重系统触感开关；CMP 通过 `HapticFeedbackPort` 调用平台能力。
- 应用默认不播放 UI 声音。

## 6. 无障碍基线

- 正文与背景对比度至少 4.5:1；大字和关键非文本图形至少 3:1。
- 交互目标至少 48×48dp，目标之间保留可区分间隔。
- 所有图标按钮提供中文语义标签；纯装饰图从语义树移除。
- TalkBack/VoiceOver 阅读顺序与视觉顺序一致；海报读作“《标题》海报”，评分读作“Bangumi 评分 8.2，12345 人参与”。
- 状态不可仅靠颜色：同步中、失败、选中均同时提供图标或文本。
- 支持 200% 字体；横向 Chip 可滚动但页面关键动作不可被挤出视口。
- 焦点进入 Dialog/Sheet 后被限制在容器内，关闭后回到触发控件。
- “减少动态效果”关闭位移、缩放和 Liquid 形变，仅保留最长 100ms 的必要淡变。
- “减少动态效果”开启时仍保留点击和横向拖动选择能力，但选中胶囊直接跳到最近目的地，不使用跟手形变、色散或弹簧过冲。
- “减少透明度”强制 `GlassTier.None`，使用不透明 `surface` 和清晰边框。

## 7. 可验证性

每个 Glass 组件必须提供 `None/Translucent/Blur/Liquid` Preview；截图测试以 `None` 和 `Translucent` 为稳定基准，Liquid 通过真机视觉回归与性能测试验证。组件验收同时覆盖 Light、Dark、高对比、200% 字体和 Reduce Motion。
