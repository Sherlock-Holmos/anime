# Bangumi 数据边界与双入口本地化清单

> 编号：`BGM-1.0`  
> 日期：2026-09-15  
> 状态：Approved。

## 1. 结论

Anime 后端是“本地目录镜像 + 上游响应缓存 + 必要时刷新 Bangumi”，不是每次请求都调用 Bangumi。双入口只决定客户端到 Anime 后端的路径：国内优先腾讯云 IP，海外优先 Cloudflare；后端到 Bangumi 的请求仍由服务器发起。

## 2. 已本地化

- 作品基础资料、中文名、原名、别名、简介、标签、播出日期、话数；
- Bangumi 评分快照和分布；
- 搜索与日历响应缓存；
- 章节、角色、制作人员、关联作品的本地镜像；
- Anime 账号、评分、评价、评论、动态、片单、关注和通知；
- Anime 会话、Bangumi OAuth token 加密存储、同步 outbox；
- 海报和头像的服务器媒体缓存。

## 3. 仍依赖 Bangumi

- 缓存未命中的搜索、作品详情和日历刷新；
- 章节、角色、人物、关联作品过期刷新；
- 首次下载 Bangumi 图片；
- Bangumi OAuth 授权和 token 刷新；
- 用户授权后的收藏/进度同步；
- 需要最新值时的 Bangumi 评分刷新。

## 4. 明确不接入

公开 v0 API 没有稳定的作品评论、长评、完整讨论回复、用户时间线和 Bangumi 内容审核接口。旧网页接口或 `next.bgm.tv` 私有接口不能作为产品契约。Anime 社区内容必须由 Anime 用户自产；作品页可以提供“前往 Bangumi 讨论”的外链或讨论数量摘要，但不复制正文。

## 5. 冷启动方案

使用官方 API/归档补齐作品资料；由管理员发布 Anime 官方主题；邀请测试用户发布首批评价和评论；在作品页明确区分 Anime 社区评分、Bangumi 评分和 Bangumi 讨论外链。不通过爬虫批量搬运用户原创内容。
